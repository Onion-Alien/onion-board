Get started

  1. Download OnionBoardSetup.exe and run it.
  2. Bun the bunny asks which mic and headphones you use and sets the rest up.
  3. In Discord or your game, pick CABLE Output as your microphone (and set Discord's Input Profile to Studio, so it doesn't filter your sounds out). Already use Voicemeeter, a mixer or OBS? Pick Another device under Send to others through and skip the virtual cable.

Windows may warn you about the download. That's normal for a free app that isn't code-signed: click More info → Run anyway (or ⋯ → Keep in Edge / Chrome). The full source is on GitHub.
