# Original voice-card illustrations

These 21 PNGs are the original illustrations for the offline character and musical
voices from [PR #2027](https://github.com/Onion-Alien/onion-board/pull/2027)
(commit `d0e6af4d2`). [PR #2028](https://github.com/Onion-Alien/onion-board/pull/2028)
introduced the 3D portraits now used by the built-in cards. The archived PNGs keep
their original filenames and bytes and are available for custom voices and future presets.

1. On GitHub, open a PNG in this folder and click **Download raw file** to save it.
2. In Onion Board's **Voice** tab, right-click a saved voice changer card and
   choose **Change picture…** → **From a file…**. Select the downloaded PNG.
   If you still need to create the voice, use **Save as a voice** first.

For a voice you created under **AI voices**, right-click its card and choose
**Edit voice…** → **Pick a picture** → **From a file…**, then select the PNG and
click **Save**.

For a text-to-speech server listed under **Custom voices**, open its **Settings** and
choose **From a link…** in the **Picture** row. On the PNG's GitHub page,
right-click the image preview, choose **Copy image address**, and paste that URL.
