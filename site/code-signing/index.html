Code signing policy

How Onion Board's Windows releases are built and signed, who can approve one, and what the app sends over the network.

Not signed yet. Onion Board has applied for free code signing from SignPath Foundation. Until it's accepted, releases are unsigned, so Windows SmartScreen may warn when you run the installer. This page says how signing will work once it is.

Who signs it

Once accepted: free code signing provided by SignPath.io, certificate by SignPath Foundation.

Only Onion Board's own programs are signed: the installer (OnionBoardSetup.exe) and the app inside it. Other projects' files it ships with, such as Python and Qt, aren't signed by this project.

How a release is built

  • Every release is built by the release workflow on GitHub Actions, from the public source code at that release's tag. Nothing built on a personal PC is signed.
  • The build scripts and the workflow are part of the source, so anyone can see how each file was made.
  • Each signing request is approved by hand by an approver (below) before anything is signed.
  • Every release lists the SHA-256 of its files, so you can check that what you downloaded is what was built.

Onion Board has one maintainer. Changes from anyone else come in as pull requests and are reviewed before they're merged. Everyone on the team uses two-factor sign-in for GitHub and SignPath.

Privacy

Onion Board only goes online for the things you use that need it, such as searching for and downloading sounds, the radio, update checks and add-ons, plus an anonymous daily count you can switch off (in the installer, or Settings → Privacy & security). The daily count never sends your IP address, your name, or anything about your PC beyond its Windows version.

What it sends and when, how to turn it off, what it changes on your PC and what the uninstaller removes: Privacy policy. Every single connection, with the switch for each: What the app does on the network. Settings → Connection → Network activity lists each one live while the app runs, and Offline mode stops them all.
