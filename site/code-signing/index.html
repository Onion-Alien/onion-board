Code signing policy

How Onion Board's Windows releases are built and signed, who can approve one, and what the app sends over the network.

Not signed yet. Onion Board has applied for free code signing from SignPath Foundation. Until it's accepted, releases are unsigned, so Windows SmartScreen may warn when you run the installer. This page says how signing will work once it is.

Who signs it

Once accepted: free code signing provided by SignPath.io, certificate by SignPath Foundation.

Only Onion Board's own programs are signed: the installer (OnionBoardSetup.exe) and the app inside it. Other projects' files it ships with, such as Python and Qt, aren't signed by this project.

How a release is built

  • Every release is built by the release workflow on GitHub Actions, from the public source code at that release's tag. Nothing built on a personal PC is signed.
  • The build scripts and the workflow are part of the source, so anyone can see how each file was made.
  • Each signing request is approved by hand by an approver (below) before anything is signed.
  • Every release lists the SHA-256 of its files, so you can check that what you downloaded is what was built.

What it does on your PC

Some features work close to Windows. Here is what each one really does.

  • Mic effect (Straight into my mic): a Windows audio effect (an APO) on the mic you pick, the same kind Equalizer APO uses. Setting it up asks Windows for admin and restarts Windows Audio. The uninstaller removes it and puts every mic's settings back.
  • Mic helper: the first time Windows asks for admin, a small helper task is added so it doesn't ask again each time you change mics. The app says so when it asks, and you can turn it off in Settings → Audio (Don't ask for admin each time). The uninstaller removes it.
  • Tor (optional): the Tor Project's official build, downloaded only when you ask for it. It carries only Onion Board's own traffic, never the rest of your PC's.
  • Hotkeys: Windows' own hotkey and raw input features, no keyboard hook. Key presses are only checked against your hotkeys, never saved or sent. Auto push-to-talk presses only the key you picked, only while your sound plays, and is off until you pick one.
  • App audio: playing another app's sound into your mic uses Windows' per-app audio capture, the same feature Discord and OBS use. Nothing is injected into the other app.
  • Onion Watch (separate add-on): watches the picture of a window you choose and plays a sound when something shows up. It never reads or changes the game's memory or input. It's a separate download, not part of the signed installer.
  • Qt: used under the LGPL-3.0, as separate DLLs in the app folder that you can swap for your own build.
  • VB-Cable (optional): a virtual audio cable by VB-Audio, a third-party driver that isn't open source. It's never bundled: the installer downloads it from VB-Audio only if you tick its box.

Privacy

Onion Board only goes online for the things you use that need it, such as searching for and downloading sounds, the radio, update checks and add-ons, plus an anonymous daily count you can switch off (in the installer, or Settings → Privacy & security). The daily count never sends your IP address, your name, or anything about your PC beyond its Windows version.

What it sends and when, how to turn it off, what it changes on your PC and what the uninstaller removes: Privacy policy. Every single connection, with the switch for each: What the app does on the network. Settings → Connection → Network activity lists each one live while the app runs, and Offline mode stops them all.

Onion Watch

Onion Watch is covered by this policy too. It is open source under the GNU GPL v3 or later, and its releases are built the same way: by GitHub Actions, from the public source at their tag (release workflow).

What it does on your PC: it watches the game windows or screens you pick for pictures you cut out, and plays a sound. A window is copied with Windows' PrintWindow and a screen with Windows' Desktop Duplication, the same APIs screen recorders and Discord's screen share use. The pictures stay in memory and are never saved or sent. It lists the open windows (titles and program names) so you can pick one. It reads Windows' idle timer (GetLastInputInfo) for alarms that ring until you're back: no keyboard or mouse hook, and it never knows which keys were pressed. It never sends keys, clicks or mouse moves to a game or any other program, never reads or writes another program's memory, and never injects code. It installs for the current user without admin rights, doesn't start with Windows, and adds no services or drivers.

Online: it only checks GitHub for updates once a day and sends an optional anonymous usage count. Both can be switched off, and the installer shows the count with a box to untick. See its privacy page. Uninstalling removes the app and asks whether to delete its settings and pictures too.

Onion Pocket (the phone add-on)

Onion Pocket is Onion Board's optional phone remote, built and released from its own public repository under the same GPL v3 or later. It ships as Python source in a zip, not as a program, and Onion Board installs it only when you click Get Onion Pocket, after checking the zip against the SHA-256 GitHub lists for it.

What it opens on your PC: off by default. When you tick Let phones on this Wi-Fi use it, Onion Board answers on one port (7475 unless you change it) on your home network only: it refuses addresses outside the local network, needs the phone's own key (in the QR code), and doesn't listen on networks Windows calls Public. A phone can only press the buttons listed in the add-on's README (play sounds, the radio, effects, the voice changer, the mic on or off for others); it can't hear the mic, read files or reach other settings.

Windows Firewall gets one inbound rule named OnionPocket (that port, Private networks, local subnet only), and only after a line on the card and Windows' own admin prompt. Removing just the add-on leaves that rule; uninstalling Onion Board removes it (Windows asks for permission first). Nothing is sent to the internet and there is no telemetry.
